## 是什么／怎么做

分页抓取默认继续到页面明确没有更多；用户显式给出的 limit 只能证明部分读取，不能当成全量终点。虚拟列表会回收旧 DOM 节点，因此每次翻页都要按稳定记录 ID 增量采集和去重，不能等最后一页再一次读取。宿主可能截断过大的 DOM 或工具输出，遇到条数异常时缩小单次批量并逐页累计。

完整性验收至少保留终止信号、每页新增数、去重后总数和首尾时间或序号；有已知完整样本时再做 ID 集合差。旧快照可以保留作证据，但不能用多份重叠快照相加冒充唯一记录数。

## 什么时候用

抓取聊天历史、评论、搜索结果、无限滚动页面或任何会虚拟化列表项的页面时使用。

## 什么时候别信

页面可能按权限、时间窗或服务端游标只返回可见子集；“没有更多”只证明当前入口的可见终点。目标平台提供官方分页 API 或导出能力时优先使用，并按其游标和一致性合同验收。
