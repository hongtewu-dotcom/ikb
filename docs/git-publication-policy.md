# Git 上传边界

仅上传经过内容检查的个人知识、通用知识，以及可独立复用的仓库代码。公司定制知识、内部业务事实、敏感材料和凭证不得上传；即使位于 personal 或 common 目录也不例外。

- `ikb-data/` 保持忽略：活动卡、原始会话、来源、附件、人物观察、运行记录和本地审查清单留在本机。
- `knowledge/` 只保存逐张检查后的公开副本，不作为活动知识真源。私有来源定位不随副本分发；副本明确说明证据未公开，不能据此宣称事实已验证。
- 检查正文、元数据、附件、测试夹具、文档示例及将新增上传的提交历史，不只检查最终工作树或目录名称。
- 不对含公司定制内容的卡片做批量关键词替换后上传；不能明确排除风险的整卡保留本地。
- 使用准确文件清单提交；推送后核对远端分支与提交 hash。不得用 `git add .`、`git push --all` 或强制推送代替内容筛选。
- 若本地历史混入不可上传内容，使用从已核对远端基线创建的隔离分支提交审过的快照，不重写原工作分支，不把该历史带入新上传。

本规则不授权自动定时上传，也不授权改写既有远端历史。
