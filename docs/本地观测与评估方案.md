# IKB 本地观测与评估方案

## 结论

IKB 不依赖 Docker、OrbStack 或任何外部观测服务。

本地真相源只有：

- `ikb-data/.system/ledger/events.jsonl`：Task、Run、交接、门禁、Verifier、Evaluation、Approval 和 Action 事件；
- `ikb-data/.system/sources/`：原始 Source 和标准化记录；
- `ikb-data/.system/runs/`：Context、Artifact、Verifier 和评估产物；
- `ikb-data/knowledge/`：Obsidian Knowledge；
- `ikb-data/governance/`：候选、推理、复核和状态视图。

观测报告是 Ledger 的可重建投影，不反向改变 Run、Knowledge 或 Approval。

## 本地能观测什么

每个 Run 可从结构化事件重建：

- 终态：`queued / running / awaiting_approval / succeeded / failed / canceled`；
- 质量态：`pass / partial / block`；
- Verifier 结果；
- Evaluation 结果及 Case 计数；
- 通过的 Gate 数量；
- Artifact 关联数量；
- 失败原因聚类和 Outer Loop 候选；
- Knowledge 引用、反馈和待确认决策；
- Ledger、Source、Knowledge 和增量状态健康度。

`succeeded` 只表示 Run 结束，不等于质量通过。只有必要 Gate、Verifier、Evaluation 和 Artifact 链齐全且通过，质量态才是 `pass`。

## 命令

```bash
# 确定性 12 Case
./bin/ikb harness eval --json

# 统一 Eval Plane
./bin/ikb harness suite list --json
./bin/ikb harness eval --suite work-protocol --json
./bin/ikb harness eval --suite work-run-quality --task-dir .agent-work/<task-id> --json

# 本地日报/周报，直接读取 Ledger
./bin/ikb report daily --json
./bin/ikb report weekly --json
./bin/ikb report weekly --format md

# 实时 HTML 观测页
./bin/ikb report serve --port 3417

# 健康与账本门禁
./bin/ikb doctor --json
./bin/ikb ledger verify --json
./bin/ikb knowledge lint --scope work --json
```

## 质量闭环

```text
Run 结构化事件
  → run-quality projection
  → 本地日报/周报/HTML
  → Verifier + Evaluation + Gate 对账
  → Outer Loop 失败聚类
  → 人工确认改进候选
  → 回归集验证
```

本地观测服务停止时，Ledger、Run、Approval、Artifact 和 Knowledge 不受影响。恢复服务后重新读取 Ledger 即可，不需要补投或恢复外部 Trace。

## 数据边界

- 不上传 Source/Knowledge 正文、Prompt、模型输出、URL、路径或 Approval 原 payload；
- HTML 服务只绑定 `127.0.0.1`，只读本机摘要；
- 评估器只读取合成 fixture、事件和 Artifact 引用，不调用模型；
- `admit` 和 `skip` 都是正常结果，知识条数不是质量指标。
