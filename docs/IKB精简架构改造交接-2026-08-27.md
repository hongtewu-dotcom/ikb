## 不再重新讨论的目标口径

主架构只有四个对象：

| 对象 | 职责 |
|---|---|
| Source | 保存原始材料、来源、版本和定位 |
| Knowledge | 保存未来任务直接复用的当前结论 |
| Inbox | 保存还需要整理、更新或人工确认的事项；文件存在即待处理 |
| Receipt | 用一个不可变格式记录一次命令或维护的输入、操作和结果 |

Knowledge 只有 `draft / verified / retired` 三个状态。helpful、incorrect、pending_review、source_confirmed 和 user_confirmed 分别属于反馈、Inbox 或 Receipt 事实，不再扩充状态机。

Receipt 只有一个 schema，通过 `kind + operations[]` 表达 remember、usage、feedback、knowledge maintenance、source sync 和 weekly。一次命令或一次定时运行最多写一份 Receipt。

Agent 公开 CLI 只有：

```text
ikb remember <path|url|text> --scope <scope>
ikb use --goal <goal> --accept <acceptance> --scope <scope>
ikb feedback <usage-id> --outcome helpful|partial|incorrect|unused [--result <path>]
```

现有 source、knowledge、task、run、artifact、doctor、ledger、backup 等命令保留为 internal，默认 HELP 不展示。facade 已穿过真实 Agent 任务；后续删除旧入口仍需先清零存量调用与历史排障引用。

Principle 是需要人确认精确正文的 Knowledge。AGENTS.md 只是 verified Principle 的短投影，不是第二真源；定时任务只能生成 Principle diff，不能自动确认或修改 AGENTS.md。
